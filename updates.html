Frequently asked questions

Everything you need to know about downloading and updating MyJournal+.

Which version should I download?

Always download the version marked "Latest" unless you specifically need an older release for compatibility or testing.

Do I need to uninstall my current version first?

Normally, no. Install the newer version over your existing MyJournal+ installation so that your app remains associated with the same application identity.

Will updating delete my journal entries?

A normal application update should not erase your application data. However, users should maintain appropriate backups of important information.

Why is Android warning me about installing an APK?

Android may display a security warning when an application is installed outside Google Play. Make sure you downloaded the APK from the official MyJournal+ website before proceeding.

How do I know when a new version is available?

Return to this official downloads page whenever you want to check for the newest release. Future versions can also be configured to notify users directly inside the MyJournal+ application.
